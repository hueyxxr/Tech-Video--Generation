适用输入

产品测评脚本、分镜表或口播稿；
用户要求筛选可生成 B-roll、产品普通运镜或 Hero Shot；
用户要求用 Dreamina 为已确认的产品视觉生成短视频。
若产品外观必须与真机一致，不能用文字臆测替代产品参考图。

固定审批流程

按以下顺序推进；每个 Gate 都必须等待用户明确确认，不能把“继续”理解为对尚未展示资产的确认。

1. 逐镜头筛选与视觉隐喻

对每个镜头输出一张精简表：

| 镜号 | 建议类型 | 是否生成产品 B-roll | 视觉隐喻 / 展示方向 |

建议类型只使用以下之一：

人物口播：保留真实人物表达；
真实实拍 / 屏录：用于游戏操作、数据、温度、续航、尺寸对比等可验证内容；
普通产品运镜：生活方式中的收纳、拿取、横握、桌面陈列等；
Hero Shot：开场、外观强调或结尾定版。
只为“普通产品运镜”和“Hero Shot”写视觉隐喻；每条不超过 20 个中文字符，并涵盖场景、质感或动作中的关键信息。不要把实测数值、游戏 UI、产品功能或未经提供的规格交给生成模型。

Gate 1： 等用户确认要生成的镜头与视觉方向。

2. 产品三视图

在 Gate 1 通过后，先要求用户上传官方产品图、实拍图或电商图（任何角度均可）。只有用户说明产品是概念产品时，才允许文字描述外观。

使用图像生成工具创建一张摄影级产品三视图：正面、侧面、背面，同一比例与基线，干净中性影棚背景。以用户图片为唯一外观参考，禁止虚构镜头、按键、接口、Logo、配色或规格。展示生成结果供用户检查。

Gate 2： 等用户确认三视图无误。后续所有静帧和视频都引用这张三视图作为产品外观锚点。

3. 单张静帧预览

为每个已确认的生成镜头各做一张单帧预览。静帧应体现最终视频的背景、构图、光线、材质与产品可见度；默认沿用原测评的横版画幅，除非用户指定其他比例。

生活方式镜头：真实自然光、适度景深、产品处于真实使用动作中；
Hero Shot：克制的暗色或中性影棚、明确轮廓光、为后期文字预留干净区域；
测试场景：只生成无数字的器材轮廓和留白，真实数据后期叠加。
Gate 3： 等用户逐张或整体确认静帧。不得在静帧未确认前提交视频生成任务。

4. Dreamina 视频生成

只有当用户明确要求“生成视频”后才提交任务。生成会消耗用户点数；一次任务在成功、失败或用户取消前，不要重复提交。
